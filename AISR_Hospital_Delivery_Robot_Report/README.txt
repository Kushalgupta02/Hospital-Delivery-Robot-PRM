AISR Sample Project Report - Overleaf package
=============================================
1. Overleaf > New Project > Upload Project > select this zip.
2. Main file: main.tex. Compiler: pdfLaTeX (Menu > Compiler).
3. Replace the sample title, member names, SAP IDs and text with your own.
   Keep the title page, page border, fonts, margins, Index and page numbering unchanged.
4. Compile twice so the Index, List of Figures and List of Tables show correct page numbers.
Files: main.tex (report), upes_logo.png (logo for the title page).
